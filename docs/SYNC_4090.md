## 本次修复

1. 分位数归一化统计改用 FP32，与训练代码一致。此前 FP64/FP32 在近乎静止的关节上可产生约 5e-5 的状态误差，可能影响离散 token。修改同时影响 SFT 和推理，已有特征指纹会随代码改变。
2. 增加 `tests/__init__.py`，避免 Linux 依赖环境里同名 tests 包遮蔽项目测试。
3. 新增只读核对脚本 `audit_physical_chain.py`、CPU 变换对照 `audit_model_transforms.py` 和只允许 mock 的 `check_bridge_interop.py`。
