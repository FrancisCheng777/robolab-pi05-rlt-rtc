## 抓稳确认与训练准入规则

新自动接管分支每轮记录 grasp_confirmed 和 grasp_confirmation_tick（第一次按 g 的 tick）。
未按 g：保留完整审计日志，但标记 grasp_not_confirmed，禁止进入 RL replay，也不计入训练批次数。
已按 g 但未进入接管区域：标记 critical_phase_not_entered，同样不训练。
已按 g 且实际触发接管：仅关键阶段的有效 transition 可以进入 replay；成功/失败标注及无故障等原有准入规则仍适用。
该规则仅应用于带 takeover_gate 元数据的新分支，不回溯修改原 A_fixed 历史数据。
